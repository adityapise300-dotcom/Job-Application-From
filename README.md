# Job Application Form

A simple job application form layout created using **HTML** and **CSS**.

## Preview

The form includes the following fields:

- First Name and Last Name
- Email
- Job Role (dropdown: HR Team, Management Team, Technical Team, Helping Staff)
- Address
- City and Pincode
- Start Date
- Upload your CV

## Technologies Used

- HTML5
- CSS3 (Flexbox for layout)

## Project Structure

```
Job-Application-From/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/adityapise300-dotcom/Job-Application-From.git
```
2. Open the project folder.
3. Open `index.html` in any web browser.
